# Workspace skills

The user supplied the skills in `skills/` for this separate workspace.

- For STM/SXM double or multiple tip analysis, read and follow `skills/stm-double-tip-analysis/SKILL.md` and use its packaged scripts.
- For every STM analysis run, rerun, or export, also read and follow `skills/saving-protocol/SKILL.md`.
- Preserve previous runs and organize evidence according to the saving protocol. Use this workspace as the run root unless the user specifies another destination.
- Skill procedures apply to relevant tasks; they do not constitute a request to start analysis. Wait for the user to specify input images or an image folder.

- After STM analysis, use `skills/stm-results-excel/SKILL.md` to write the per-image Excel rundown into the run's `overall-results/` folder.
